Web Scraper for Headlines & Quotes

Project Description

This project extracts quotes and author names from a public practice website using Python.

Technologies Used

- Python
- Requests
- BeautifulSoup
- JSON

How It Works

1. Sends an HTTP request to the website.
2. Reads the HTML content.
3. Extracts quotes and author names.
4. Saves the extracted data into a JSON file.

Website Used

https://quotes.toscrape.com/

This is a public practice website designed for learning web scraping.

Output

Successfully scraped 10 quotes and saved them in quotes.json.
