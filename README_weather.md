Weather App with Live OpenWeather API 🌦️

Project Description

This project is a Python-based Weather Application that fetches real-time weather information using the OpenWeather API.

Users can enter a city name and view its current weather details and a short forecast.

Features

- Live temperature in Celsius.
- Humidity information.
- Current weather description.
- Short weather forecast.
- Error handling for invalid cities.
- API integration using Python Requests.

Technologies Used

- Python
- OpenWeather API
- Requests Library
- JSON

Requirements

Install the Requests library:

pip install requests

How to Run

1. Run the "weather_app.py" file.
2. Enter your OpenWeather API key when prompted.
3. Enter a city name.
4. View the weather report and forecast.

API Key Security

The API key is entered at runtime and is not stored in the source code.

The API key is not included in this GitHub repository.
