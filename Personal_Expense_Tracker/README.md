Personal Expense Tracker with CSV

1. Project Description

Personal Expense Tracker is a Python-based application that helps users record and manage their daily expenses. It stores expense details in a CSV file and displays category-wise expense summaries.

2. Objectives

- To record daily expenses.
- To view all recorded expenses.
- To filter expenses by category.
- To calculate total expenses for each category.
- To save expense records permanently using CSV files.

3. Features

1. Add Expense
2. View Expenses
3. Filter Expenses
4. Category Summary
5. Exit the Program

4. Technologies Used

- Python
- CSV Module
- File Handling
- Date Validation

5. Project Files

- "expense_tracker.py" – Main Python program.
- "expenses.csv" – Stores expense records.
- "README.md" – Project documentation.

6. How to Run

1. Open the project in a Python editor.
2. Run the "expense_tracker.py" file.
3. Select an option from the menu.
4. Enter the required expense details.
5. View expenses and category summaries.

7. Sample Data

The project contains 10 sample expense records with different categories, amounts, dates, and descriptions.

8. Problem Fixed

One problem I faced was storing expense records permanently. Initially, data could be lost after restarting the program. I fixed this problem by using CSV file handling to save and retrieve expense records.

9. Learning Outcomes

- Learned Python functions.
- Understood CSV file operations.
- Practiced file handling.
- Learned input validation.
- Understood grouping and calculating data.

10. Conclusion

This project helped me understand how Python can be used to develop a simple expense management application. It improved my knowledge of file handling, CSV operations, and data processing.
